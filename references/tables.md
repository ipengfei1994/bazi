## 二、作用关系判断三要素

### 位置要素

- 月令/日支/时支：影响力强，优先判断
- 年柱：影响力偏弱，远隔作用需打折
- 透干 vs 藏干：天干显用易被作用，地支藏干需看本气/中气/余气

### 距离要素

- **六合必须紧邻**：六合仅在相邻柱之间发生，隔位不合
  - 甲年干 + 己月干 → 相邻可合
  - 甲年干 + 己时干 → 隔两柱，不合
- **三合允许隔位**：三支可散布年/月/日柱，但力量有差异
  - 三支紧邻：力量完整
  - 三支分散：力量减半，仍可成局

### 合化成功条件

- **六合合化**：两支紧贴，且月令为化神五行，化神透干更佳；否则仅为"合绊"，不化
  - 例：寅亥合木，需月令为寅/卯/辰月，且木气透出
- **三合局合化**：三支齐全（允许隔位），月令为化神旺相之地，无冲破，则能量凝聚成局
  - 例：申子辰三合水，需月令为亥/子/丑月，水气旺相

## 五、大运排法精确规则

### 顺逆方向

- **阳男阴女**：顺行（从月柱往后排，即下一个节气方向）
- **阴男阳女**：逆行（从月柱往前排，即上一个节气方向）

### 起运岁数折算

1. 阳男阴女：从出生日顺数至**下一个**换月节气（交节）
2. 阴男阳女：从出生日逆数至**上一个**换月节气（交节）
3. 折算规则：
   - 每 **3天** = **1年** 起运
   - 余数：**1天** = **4个月**
   - **1个时辰** = **10天**

**示例**：总天数 22 天 → 7年（21天）+ 4个月（余1天折4个月）

### 大运排列

每步大运管 10 年，依起运方向（顺/逆）依次排列天干地支。

## 六、流年吉凶作用类型速查

| 类型 | 效果 |
|---|---|
| **合** | 天干五合、地支六合三合 → 新的能量关系建立（未必全吉） |
| **冲** | 六冲到位 → 动摇、变动、破旧立新（结合喜忌） |
| **刑** | 触发原局三刑 → 刑伤、内耗、官非疾病 |
| **会** | 三会方 → 某季能量极盛，所在宫位人事旺盛 |
| **破** | 相破 → 破碎消耗，暗中损失 |
| **伏吟** | 流年干支与命局某柱相同 → 该柱对应人事重复、停滞、加倍 |
| **反吟** | 流年与命局某柱天克地冲 → 剧烈变动，连根拔起 |

### 喜忌叠加原则

| 喜用神遇 | 流年效果 |
